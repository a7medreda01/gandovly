# دليل تجهيز وحزم بيانات المتجر — الإصدار 1.3.0 الشامل
# MeCart Store Seeding & Migration Engine Specification

هذا الدليل هو المرجع الهندسي والتشغيلي المعتمد لإعداد قوالب المتاجر، تصدير واستيراد حزم البيانات (Store Packages بصيغة ZIP)، وضبط الهوية وتخطيط الواجهة لجميع منصات MeCart.

---

## 1. التحديثات والميزات الجديدة في الإصدار 1.3.0

1. **4 قوالب متكاملة للواجهة الرئيسية (Storefront Themes)**:
   - `classic`: الشكل الكلاسيكي المتوازن — ملائم لكافة الأنشطة العامة ومتاجر التجزئة.
   - `cards`: شكل الكروت البارزة — كروت منتجات وأقسام ذات ظلال أنيقة، مثالي للإلكترونيات والأجهزة.
   - `editorial`: المجلة التحريرية الفخمة — تصميم راقٍ ذو كروت أفقية ومساحات واسعة، مثالي للأثاث، الديكور، والموضة.
   - `discovery`: لوحة الاكتشاف التفاعلية — شريط بحث علوي بارز وشبكة أقسام دائرية، ملائم للسوبرماركت والهايبر ماركت.

2. **بانرات مستقلة لكل قالب (Theme-Specific Banners)**:
   - يتيح النظام تخصيص بانر كمبيوتر وموبايل وعنوان وزر مستقل لكل قالب ضمن كائن `themeBanners` في `storeLayout`.
   - عند تبديل القالب، تظهر تلقائياً البانرات المخصصة لذلك القالب دون الحاجة لإعادة رفعها أو فقدان إعدادات القالب الآخر.

3. **16 نوع سكشن للواجهة الرئيسية (16 Homepage Section Types)**:
   - إضافة 10 أنواع سكاشن تفاعلية جديدة (سلايدر الهيرو، كاروسيل المنتجات، آراء العملاء، شبكة الأقسام، العداد التنازلي، النشرة البريدية، شريط الإحصائيات، الدعوة للشراء الكاملة، الفيديو، وكتل الماركداون) بجانب السكاشن السابقة (الهيرو، المنتجات، البانر الإعلاني، المميزات، الماركات، والأقسام).

4. **نظام ضغط الصور الذكي وتحسين الأداء (Image Compression & Performance)**:
   - خيار تفعيل الضغط التلقائي `enableImageCompression` وتحديد الحجم الأقصى بالكيلوبايت `maxImageCompressionKb` (افتراضي 150KB).
   - يتم ضغط الصور محلياً بدقة فائقة قبل الرفع مما يقلل استهلاك السيرفر ويسرع تحميل المتجر للعملاء.

5. **زر "شراء الآن" السريع (Quick Buy Now Button)**:
   - خيار `enableBuyNow` يظهر زراً سريعاً مميزاً بجانب "إضافة للسلة" في نافذة وصفحة المنتج ينقل العميل مباشرة لإنهاء الطلب باختياراته.

6. **تخصيص أنماط العرض والتأثيرات الحركية (Visuals & Animations)**:
   - أنماط كروت المنتجات `productCardStyle`: `modern` (عصري بدون حواف حادة مع ظل خفيف)، `bordered` (مؤطر بحدود ناعمة)، `minimal` (بسيط ومسطح).
   - نمط شارة الخصم `discountBadgeMode`: `percent` (نسبة مئوية %)، `amount` (قيمة التوفير بالعملة)، `both` (كلاهما).
   - التحكم بتأثيرات الحركة: `enableHomeSectionAnimations`، `enableProductCardAnimations`، و `enableProductPageAnimations`.
   - تثبيت الهيدر العلوي `stickyHeader`.

## 2. بنية ملف الأرشيف المضغوط (ZIP Structure)

يجب أن توضع الملفات التالية في جذر الأرشيف مباشرة (Root) بدون مجلد أب:

```
├── manifest.json              # بيانات تعريف الحزمة والإصدار والإحصائيات
├── settings.json              # إعدادات المتجر والهوية و storeLayout
├── categories.json            # أقسام المتجر وتصنيفاته
├── products.json              # المنتجات مع خيارات الأسعار والصور والمتغيرات
├── delivery_zones.json        # مناطق التوصيل والأسعار
├── branches.json              # الفروع ومواعيد العمل (اختياري)
├── modifier_groups.json       # خيارات وإضافات المنتجات (اختياري)
├── preparation_groups.json    # طرق التحضير والتجهيز (اختياري)
├── resources.json             # الموارد ومواعيد الحجز للمسارات المتخصصة (اختياري)
├── batches.json               # تشغيلات الصلاحية للأغذية (اختياري)
├── digital_assets.json        # الملفات الرقمية للبيع (اختياري)
├── uploads/                   # مجلد الوسائط والصور المرفوعة
│   ├── branding/              # الشعار، الأيقونة، وبانرات القوالب
│   ├── categories/            # صور الأقسام
│   └── products/              # صور المنتجات والمتغيرات
└── private_assets/            # الملفات الرقمية المدفوعة والكتب الرقمية (اختياري)
```

## 4. تفاصيل الـ 16 نوعاً لسكاشن الصفحة الرئيسية (Section Kinds)

| نوع السكشن (kind) | الوصف والاستخدام | الخصائص والبيانات التابعة له |
|---|---|---|
| `hero` | بانر رئيسي عريض أو منقسم بنصوص وزر | `title`, `subtitle`, `eyebrow`, `buttonText`, `link`, `imageUrl`, `mobileImageUrl`, `layout: split\|overlay` |
| `products` | شبكة كروت منتجات ديناميكية مع فلترة | `title`, `subtitle`, `source: featured\|latest\|offers\|bestsellers\|category\|manual`, `categoryId`, `productIds`, `limit`, `buttonText`, `link` |
| `product_carousel` | سلايدر منتجات أفقي أنيق قابل للسحب | نفس خصائص `products` مع عرض انسيابي أفقي ملائم للموبايل والكمبيوتر |
| `hero_slider` | سلايدر بانرات متعدد الشرائح بأعلى الصفحة | مصفوفة `slides` (كل شريحة لها `title`, `subtitle`, `buttonText`, `link`, `imageUrl`, `mobileImageUrl`, `overlayOpacity`, `textColor`) |
| `categories` | شريط أقسام دائري أفقي مع تمرير انسيابي | يقرأ الأقسام النشطة تلقائياً من `categories.json` مع صورها |
| `categories_grid` | شبكة كروت عصرية مخصصة لأقسام المتجر | يقرأ الأقسام مع صورها البارزة وتأثيرات التكبير عند التمرير |
| `banner` | بانر إعلاني أو ترويجي بنص عريض وزر إجراء | `title`, `subtitle`, `eyebrow`, `imageUrl`, `mobileImageUrl`, `backgroundColor`, `textColor`, `buttonText`, `link` |
| `features` | بطاقات مميزات المتجر والضمانات | مصفوفة `items` (كل عنصر له `title`, `text`, `icon` كاسم Bootstrap Icon مثل `bi-truck`، و `link`) |
| `brands` | شريط شعارات الماركات والشركاء | مصفوفة `items` (كل عنصر له `title`, `imageUrl`, `link`) |
| `testimonials` | بطاقات آراء وتقييمات العملاء الموثقة | مصفوفة `testimonials` (كل عنصر له `name`, `role`, `text`, `rating: 1-5`, `avatarUrl`) |
| `stats` | شريط عدادات وإحصائيات المتجر | مصفوفة `items` (كل عنصر له `title` كالرقم، `text` كوصف، و `icon`) |
| `countdown` | سكشن العروض المحدودة بعداد تنازلي مباشر | `title`, `subtitle`, `countdownTarget` (بتنسيق ISO 8601 مثل `2026-12-31T23:59:59Z`), `buttonText`, `link` |
| `cta_full` | نداء لاتخاذ إجراء عريض (Full-width Call to Action) | `title`, `subtitle`, `buttonText`, `link`, `backgroundColor`, `textColor` |
| `newsletter` | نموذج الاشتراك في النشرة البريدية | `title`, `subtitle`, `buttonText` |
| `video` | سكشن فيديو ترويجي للمنتجات | `title`, `subtitle`, `videoUrl` (رابط MP4 أو يوتيوب), `imageUrl` كغلاف, `buttonText`, `link` |
| `markdown` | كتلة محتوى نصي غني أو تعليمات مخصصة | `title`, `subtitle`, `markdownContent` (نص ماركداون منسق) |

## 6. صور المتجر والوسائط (Media Guidelines)

- يُشترط أن توضع الصور داخل مجلد `uploads/` داخل الـ ZIP.
- المسارات داخل الـ JSON تكتب كمسارات نسبية تبدأ بـ `/uploads/` مثل `/uploads/products/item-01.webp`.
- **الصيغ المدعومة**: `.webp`, `.png`, `.jpg`, `.jpeg`, `.avif`, `.gif`, `.ico`. نوصي بصيغة `WebP` لأعلى جودة وأقل حجم.
- **الأبعاد المقترحة**:
  - صور المنتجات: مربعة `1000x1000` أو `1200x1200` بكسل بخلفية نظيفة.
  - صور الأقسام: مربعة أو دائرية `600x600` بكسل.
  - بانرات سطح المكتب: عريضة `1920x600` أو `1920x800` بكسل.
  - بانرات الموبايل: رأسية متناسبة `1080x1350` أو `1080x1080` بكسل.
  - شعار المتجر: شفاف بصيغة PNG أو WebP بأبعاد تناسب شريط التنقل (`300x100` تقريباً).
- **الضغط التلقائي**: عند تفعيل `enableImageCompression`، يضمن النظام تحجيم الصور آلياً لتكون أقل من الحجم المحدد بالكيلوبايت قبل حفظها.

## 7. آلية التصدير والاستيراد (Export & Import Engine)

1. **تصدير حزمة المتجر (Export)**:
   - يضغط كافة الكتالوجات (المنتجات، الأقسام، المتغيرات، خيارات التجهيز، مناطق التوصيل، الإعدادات، والهوية).
   - يصدر كائن `storeLayout` متضمناً القالب المختار، بانرات القوالب المستقلة `themeBanners`، وكافة السكاشن الـ 16.
   - يعيد حزم كافة ملفات الصور المرفوعة محلياً داخل `uploads/media/` ويعيد كتابة الروابط تلقائياً لضمان عزل المتاجر (Multi-Tenant Isolation).
   - يضمن ملف `manifest.json` بإصدار `1.3.0` وملف `SEED_GUIDE.md`.

2. **استيراد حزمة المتجر (Import)**:
   - **الاستيراد لمتجر فارغ (Clean Import)**: يزرع المتجر الجديد بالكامل ويعيد ربط معرفات الأقسام والمنتجات والسكاشن تلقائياً داخل قاعدة البيانات دون أي تعارض.
   - **المزامنة الذكية لمتجر قائم (Smart Sync)**: في حال وجود بيانات مسبقة في المتجر، يقوم النظام بتحديث نصوص المنتجات والأقسام، وتحديث إعدادات الهوية و`storeLayout` والبانرات والسكاشن الجديدة بأمان تام دون حذف سجل الطلبات التاريخي أو إتلاف بيانات العملاء.
