# دليل تجهيز وحزم بيانات المتجر — الإصدار 1.3.0 الشامل (PostgreSQL Ready)
# MeCart Store Seeding & Migration Engine Specification

هذا الدليل هو المرجع الهندسي والتشغيلي المعتمد لإعداد قوالب المتاجر، تصدير واستيراد حزم البيانات (Store Packages بصيغة ZIP)، وضبط الهوية وتخطيط الواجهة والوسائط (الصور والفيديوهات) لجميع منصات MeCart على قاعدة بيانات PostgreSQL.

---

## 1. الميزات والخصائص الرئيسية (v1.3.0)

1. **4 قوالب متكاملة للواجهة الرئيسية (`Storefront Themes`)**:
   - `classic`: الشكل الكلاسيكي المتوازن — ملائم لكافة الأنشطة العامة ومتاجر التجزئة والمطاعم.
   - `cards`: شكل الكروت البارزة — كروت منتجات وأقسام ذات ظلال أنيقة، مثالي للإلكترونيات والأجهزة.
   - `editorial`: المجلة التحريرية الفخمة — تصميم راقٍ ذو كروت أفقية ومساحات واسعة، مثالي للأثاث، الديكور، والموضة.
   - `discovery`: لوحة الاكتشاف التفاعلية — شريط بحث علوي بارز وشبكة أقسام دائرية، ملائم للسوبرماركت والهايبر ماركت.

2. **بانرات مستقلة لكل قالب (`themeBanners`) وملفات تخطيط مستقلة (`homeProfiles`)**:
   - يتيح `themeBanners` تخصيص بانر كمبيوتر (`desktopUrl`) وموبايل (`mobileUrl`) وعنوان وزر ورابط لكل قالب (`classic`, `cards`, `editorial`, `discovery`).
   - يتيح `homeProfiles` حفظ سكشنات وتخطيط `useCustomHome` مستقل لكل قالب حتى لا تضيع تنسيقات القالب عند التبديل بينها.

3. **17 نوع سكشن للواجهة الرئيسية (`17 Homepage Section Kinds`)**:
   - تشمل سكشن `video_carousel` (معرض الفيديوهات الأفقي القابل للتمرير) و `video` (فيديو مفرد) بجانب: `hero`, `hero_slider`, `products`, `product_carousel`, `categories`, `categories_grid`, `banner`, `features`, `brands`, `testimonials`, `stats`, `countdown`, `cta_full`, `newsletter`, `markdown`.

4. **دعم الفيديو الأصلي داخل الحزمة (`MP4 / WebM`) وضغط الصور القابل للتخصيص**:
   - يدعم المحرك تضمين ملفات الفيديو (`.mp4` و `.webm`) داخل `uploads/` حتى **30 ميجابايت** للفيديو الواحد بدون إتلاف أو إعادة ضغط.
   - يدعم ضغط الصور تلقائياً وفق `enableImageCompression` و `maxImageCompressionKb` (النطاق المسموح: `30` إلى `1024` كيلوبايت، والافتراضي `150 KB`). عند ضبط `enableImageCompression: false` تمر الصور الأصلية الآمنة كما هي (حتى `5 MB`).

5. **التوافق الكامل مع قاعدة بيانات PostgreSQL (التوقيت العالمي UTC)**:
   - جميع حقول التواريخ والأوقات (`updatedAt`, `exportedAt`, `receivedAt`, `countdownTarget`, `expiresAt`, ...) **يجب** أن تكون بصيغة **ISO-8601 UTC المنتهية بحرف `Z`** مثل `"2026-11-23T12:00:00Z"`.

6. **أوضاع الاستيراد المرنة (Clean Import / Smart Merge / Clean Replace)**:
   - **استيراد إلى متجر فارغ (Clean Import)**: زرع كامل للكتالوج والسكاشن وإعادة ربط جميع المعرّفات تلقائياً.
   - **الدمج الذكي لمتجر قائم (`cleanFirst=false`)**: يحدّث الأقسام والمنتجات المطابقة، ويضيف الأقسام والمنتجات والفروع ومناطق التوصيل ومجموعات الإضافات الناقصة، ويحدّث الإعدادات و`storeLayout` مع إعادة ربط المعرّفات دون المساس بالطلبات التاريخية أو العملاء.
   - **الاستبدال الكامل (`cleanFirst=true`)**: يمسح الكتالوج القديم ويعيد زرع الحزمة من الصفر (مسموح فقط إذا لم تكن هناك طلبات مرتبطة بالمنتجات القديمة).

## 2. بنية ملف الأرشيف المضغوط (ZIP Structure)

**شرط حرج:** يجب وضع الملفات التالية في **جذر الأرشيف مباشرة (ZIP Root)** دون وضعها داخل مجلد أب خارجي، وبحد أقصى: **150 MB** لحجم الـ ZIP، و **250 MB** بعد فك الضغط، و **10,000** ملف/مجلد:

```
my_store_package.zip (Root)
├── manifest.json              # [إلزامي] تعريف الحزمة والإصدار والإحصائيات
├── settings.json              # [إلزامي] إعدادات المتجر والهوية و storeLayout
├── categories.json            # [إلزامي] أقسام المتجر وتصنيفاته
├── products.json              # [إلزامي] المنتجات والأسعار والصور والمتغيرات والإضافات
├── delivery_zones.json        # [إلزامي] مناطق ورسوم التوصيل الهرمية
├── branches.json              # [اختياري] الفروع ومواعيد العمل (مصفوفة [] إن وجدت أو فارغة)
├── modifier_groups.json       # [اختياري] مجموعات الإضافات والاختيارات
├── preparation_groups.json    # [اختياري] مجموعات طرق التحضير والتجهيز
├── resources.json             # [اختياري] موارد الحجز للمسار المتخصص Booking
├── batches.json               # [اختياري] تشغيلات الصلاحية للمنتجات الغذائية Perishable
├── digital_assets.json        # [اختياري] بيانات الملفات الرقمية المدفوعة Digital / Subscription
├── uploads/                   # [اختياري/إلزامي عند وجود وسائط] مجلد الصور والفيديوهات
│   ├── branding/              # الشعار، الأيقونة، بانرات القوالب
│   ├── categories/            # صور الأقسام
│   ├── products/              # صور المنتجات والمتغيرات
│   └── videos/                # أو uploads/media/ — فيديوهات MP4 / WebM وصور مُصدّرة
└── private_assets/            # [اختياري] الملفات الرقمية المدفوعة (ZIP, PDF...)
```

ملاحظة: يقبل المحرك كل الملفات بصيغة JSON Array مباشرة `[...]` أو داخل مغلف `{ "data": [...] }`، كما يقبل إصدارات `manifest.version`: `"1.0.0"`, `"1.1.0"`, `"1.2.0"`, `"1.3.0"`, `"1.4.0"`.

* قيم `businessDomain` المعتمدة: `"Supermarket"`, `"Restaurant"`, `"Pharmacy"`, `"AutoParts"`, `"Electronics"`, `"GeneralRetail"`.

### ب) `categories.json`

  - `id` رقم فريد، `nameAr` غير فارغ (حتى 200 حرف)، `categoryId` يطابق `id` موجود فعلياً في `categories.json`.

* `level`: `"Macro"` | `"Sub"` | `"Micro"`. يدعم المحرك ربط `parentZoneId` بأي ترتيب داخل الملف.
* `branches.json`: مصفوفة تحتوي `name`, `phone`, `address`, `isActive`, `workingHoursText`.

### هـ) `modifier_groups.json` و `preparation_groups.json`
* **`modifier_groups.json`**: مصفوفة من المجموعات، كل مجموعة تحتوي `id`, `nameAr`, `nameEn`, `isRequired`, `minSelection`, `maxSelection`, `displayOrder`, ومصفوفة `options`: `[{ "nameAr": "...", "nameEn": "...", "price": 15.00, "isAvailable": true, "displayOrder": 1 }]`.
* **`preparation_groups.json`**: نفس البنية مع حقل `pricingType` للخيار (`"AddOn"` أو `"PerKg"` أو `"Fixed"`).

### و) الملفات المتخصصة الاختيارية (`resources.json`, `batches.json`, `digital_assets.json`)
* **`resources.json`**: `id`, `name`, `capacity` (1..1000), `isActive`, `opensAt` (`"09:00"`), `closesAt` (`"18:00"` أكبر من `opensAt`), `daysOfWeek` (`"0,1,2,3,4,5,6"`), `blackoutDates` (`["2026-12-25"]` بصيغة `yyyy-MM-dd`).
* **`batches.json`**: `productId` (لمنتج بوضع `Perishable`), `lotNumber`, `expiresOn` (`"2026-12-30"`), `remainingQuantity` (>= 0), `isBlocked`, `receivedAt` (UTC بصيغة `2026-11-23T12:00:00Z`).
* **`digital_assets.json`**: `[{"productId": 501, "fileName": "ebook.pdf", "filePath": "private_assets/0.pdf"}]` لمنتجات `Digital` أو `Subscription` مع وضع الملف داخل `private_assets/`.

### جدول الـ 17 نوعاً لسكاشن الصفحة الرئيسية (`Section Kinds`):

| نوع السكشن (`kind`) | الوصف والاستخدام | الخصائص والبيانات التابعة له |
|---|---|---|
| `hero` | بانر رئيسي عريض أو منقسم بنصوص وزر | `title`, `subtitle`, `eyebrow`, `buttonText`, `link`, `imageUrl`, `mobileImageUrl`, `layout: split\|overlay`, `overlayOpacity` (0..80) |
| `hero_slider` | سلايدر بانرات متعدد الشرائح بأعلى الصفحة | `slides[]`: (`title`, `subtitle`, `buttonText`, `link`, `imageUrl`, `mobileImageUrl`, `overlayOpacity`, `textColor`) |
| `products` | شبكة كروت منتجات ديناميكية | `title`, `subtitle`, `source: featured\|latest\|offers\|bestsellers\|category\|manual`, `categoryId`, `productIds[]`, `limit` (1..12), `buttonText`, `link` |
| `product_carousel` | سلايدر منتجات أفقي أنيق قابل للسحب | نفس خصائص `products` (إجمالي سكاشن المنتجات والكاروسيل معاً بحد أقصى 8) |
| `categories` | شريط أقسام دائري أفقي | يقرأ الأقسام النشطة تلقائياً من `categories.json` |
| `categories_grid` | شبكة كروت عصرية لأقسام المتجر | يقرأ الأقسام مع صورها البارزة |
| `banner` | بانر إعلاني أو ترويجي عريض | `title`, `subtitle`, `eyebrow`, `imageUrl`, `mobileImageUrl`, `backgroundColor` (`#RRGGBB`), `textColor` (`#RRGGBB`), `buttonText`, `link` |
| `features` | بطاقات مميزات المتجر والضمانات | `items[]` (حد أقصى 12): `title`, `text`, `icon` (بنمط `bi-*` مثل `bi-truck`), `link` |
| `brands` | شريط شعارات الماركات والشركاء | `items[]` (حد أقصى 12): `title`, `imageUrl`, `link` |
| `testimonials` | بطاقات آراء وتقييمات العملاء | `testimonials[]`: `name`, `role`, `text`, `rating` (1..5), `avatarUrl` |
| `stats` | شريط عدادات وإحصائيات المتجر | `items[]`: `title` (الرقم), `text` (الوصف), `icon` (`bi-*`) |
| `countdown` | سكشن العروض المحدودة بعداد تنازلي | `title`, `subtitle`, `countdownTarget` (`2026-12-31T23:59:59Z`), `buttonText`, `link` |
| `cta_full` | نداء لاتخاذ إجراء عريض | `title`, `subtitle`, `buttonText`, `link`, `backgroundColor`, `textColor` |
| `newsletter` | نموذج الاشتراك في النشرة البريدية | `title`, `subtitle`, `buttonText` |
| `video` | سكشن فيديو ترويجي مفرد | `title`, `subtitle`, `videoUrl` أو `videos[0]`, `imageUrl` (غلاف), `buttonText`, `link` |
| `video_carousel` | **معرض ريلز/فيديوهات أفقي (بحد أقصى 8 فيديوهات)** | `videos[]` (`url`, `mobileUrl`, `posterUrl`, `title`, `titleEn`, `link`), `videoAspect` (`16/9\|9/16\|1/1\|4/5\|21/9\|4/3`), `videoMobileAspect`, `videoFit` (`cover\|contain`), `videoWidth` (`container\|full`), `videoMuted`, `videoShowControls`, `videoLoop` |
| `markdown` | كتلة محتوى نصي منسق | `title`, `subtitle`, `markdownContent` |

**ملاحظة قيود التحقق (`StoreLayout Validation`):**
- أقصى عدد سكاشن في الصفحة الرئيسية: **16 سكشن**، ولكل سكشن `id` فريد يطابق `^[a-zA-Z0-9_-]{1,64}$`.
- الألوان (`backgroundColor`, `textColor`): إما `""` فارغ أو بصيغة HEX كاملة من 6 خانات (`#1E293B`).
- روابط السكاشن والشرائح والفيديوهات وبانرات القوالب (`SafeLink`): يجب أن تبدأ بـ `/menu` أو `/account` أو `/product/{id}` (مع معاملات مسموحة فقط: `?category={id}`, `sort=latest|offers|bestsellers|name|price_asc|price_desc`, `search=...`).
- عند وجود روابط مثل `/menu?category=103` أو `/product/1221` أو `section.categoryId` أو `section.productIds`، يقوم المحرك تلقائياً بإعادة ربطها بالمعرفات الجديدة في المتجر الوجهة؛ لذا تأكد دائماً أن المعرفات في الروابط تطابق فعلياً الـ `id` داخل `categories.json` و `products.json` في نفس الحزمة!

---

## 5. قواعد الوسائط (الصور والفيديوهات)

1. **الصيغ المسموحة داخل `uploads/`**:
   - **الصور:** `.webp`, `.png`, `.jpg`, `.jpeg`, `.jfif`, `.avif`, `.gif`, `.ico`, `.bmp`, `.tif`, `.tiff`, `.heic`, `.heif`, `.jxl` (مع مطابقة التوقيع الفعلي للملف، وبأبعاد لا تتجاوز `25` مليون بكسل). ممنوع الملفات التنفيذية وملفات `SVG`.
   - **الفيديوهات:** `.mp4` (بتوقيع `ftyp` صحيح) و `.webm` (بتوقيع EBML صحيح)، بحد أقصى **30 MB** للملف الواحد.
2. **ضغط الصور أثناء الاستيراد**:
   - يقرأ المحرك قيمة `storeLayout.maxImageCompressionKb` (افتراضي `150 KB`) ويحول الصور الأكبر من الحد إلى `WebP` عالية الكفاءة مع الحفاظ التلقائي على أيقونات `.ico`.
3. **الروابط الخارجية**:
   - الروابط الكاملة بصيغة `https://...` (مثل `images.unsplash.com`) تبقى كما هي وتعمل دون الحاجة لوضعها داخل `uploads/`.

## 6. استكشاف أخطاء الاستيراد وحلها (Troubleshooting)

| رسالة الخطأ أو العَرَض | السبب الحقيقي | الحل الصحيح |
|---|---|---|
| `42601: syntax error at or near "@"` | استدعاء T-SQL قديم (`sp_getapplock`) على PostgreSQL | تم التحويل في هذا الإصدار لاستخدام `pg_advisory_xact_lock` — تأكد من نشر أحدث نسخة Backend (`Rebuild`). |
| خطأ `DateTimeKind.Unspecified` / `timestamp with time zone` | تواريخ داخل الـ JSON بدون علامة UTC `Z` | أضف `Z` في نهاية كل تاريخ (مثال: `"2026-11-23T12:00:00Z"`). المحرك أيضاً يطبعها تلقائياً عند الحفظ والتصدير. |
| `نوع ملف غير مسموح داخل مجلد الصور: .mp4` | حزمة قديمة/نسخة محرك لا تدعم الفيديو داخل `uploads/` | استخدم التحديث الحالي؛ يدعم `.mp4` و `.webm` داخل `uploads/` مباشرة حتى 30MB. |
| `ملف وسائط مفقود أو مسار غير آمن` | مسار `/uploads/...` مكتوب في الـ JSON ولكن الملف غير موجود فعلياً في الـ ZIP | تأكد من وجود الملف بنفس المسار (أحرف صغيرة/كبيرة مطابقة) داخل مجلد `uploads/`، أو أزل المرجع الفارغ. |
| روابط بانر أو سكشن في المتجر الجديد تفتح قائمة فارغة | رابط `/menu?category=1` يشير إلى `id` قديم غير موجود في `categories.json` | اجعل رقم `category=` يطابق الـ `id` الفعلي للقسم في `categories.json` ليُعاد ربطه تلقائياً بالمتجر الجديد. |
| `لا يمكن مسح الكتالوج بالكامل لوجود طلبات مرتبطة` | تفعيل `cleanFirst=true` على متجر به طلبات تاريخية | ألغِ تحديد "استبدال البيانات بالكامل" لاستخدام الدمج الذكي (`cleanFirst=false`)، أو استورد الحزمة إلى متجر جديد فارغ. |
