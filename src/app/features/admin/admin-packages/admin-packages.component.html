تصدير حزمة المتجر (Export Store ZIP)

تصدير الكتالوج والإعدادات والصور المرتبطة

يقوم المحرك بقراءة إعدادات المتجر الحالية، الفروع، مناطق التوصيل، الأقسام، وكافة المنتجات وصورها، وتغليفها داخل ملف .zip منظم يحتوي على manifest.json ودليل SEED_GUIDE.md.

  • تفريغ كامل للمنتجات والأقسام والأسعار بصيغة JSON نظيفة
  • تجميع كافة الصور ومجلد uploads/ بجودتها الأصلية
  • جاهز للاستخدام كنسخة احتياطية (Backup) أو كقالب لعميل آخر

استيراد وزرع حزمة متجر (Import & Seed)

رفع وتثبيت بيانات وصور قالب متجر جديد

ارفع ملف حزمة المتجر بصيغة .zip لاستيراد المنتجات والأقسام والصور تلقائيًا إلى المتجر المحدد.

دليل إرشادات زرع وتجهيز الحزم (SEED_GUIDE.md)

1. الهيكل المعتمد لحزمة المتجر (Package Structure)
my_store_package.zip
├── manifest.json       # معلومات القالب، رقم الإصدار، نوع النشاط
├── settings.json       # إعدادات المتجر والهوية والحسابات
├── categories.json     # قائمة الأقسام والتصنيفات
├── products.json       # قائمة المنتجات والأسعار والمواصفات
├── delivery_zones.json # مناطق ورسوم التوصيل
└── uploads/            # مجلد الصور المنظم (branding, categories, products)
2. أنواع الأنشطة المدعومة (Business Domains)
  • Supermarket: سوبر ماركت، بقالة، تجزئة طازجة ومجمدة (دعم البيع بالقطعة أو الكيلو).
  • Restaurant: مطاعم، كافيهات، وجبات سريعة، صوصات وإضافات.
  • Pharmacy: صيدليات، مستحضرات تجميل، أدوية ومستلزمات طبية.
  • AutoParts: قطع غيار سيارات، موديلات، ورقم OEM.
  • Electronics: أجهزة منزلية وإلكترونيات وهواتف وضمان.
  • GeneralRetail: محلات ملابس وأزياء ومقاسات وألوان.
3. التثبيت المستقل (Standalone Installation)

إذا رغبت في استخراج هذا القالب وتركيبه كـ موقع مستقل بالكامل لعميل خاص على سيرفره المنفصل، يتم تصدير الحزمة وضبط المتغير في appsettings.json: "DeploymentMode": "StandaloneInstance".
