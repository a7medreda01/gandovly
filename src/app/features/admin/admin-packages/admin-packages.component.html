تصدير حزمة المتجر (Export Store ZIP)

تصدير الكتالوج والإعدادات والصور المرتبطة

يقوم المحرك بقراءة إعدادات المتجر الحالية، الفروع، مناطق التوصيل، الأقسام، وكافة المنتجات وصورها وفيديوهات MP4/WebM، وتغليفها داخل ملف .zip متوافق مع PostgreSQL يحتوي على manifest.json ودليل SEED_GUIDE.md. الإصدار 1.3.0 يشمل القوالب الـ 4، الـ 17 نوع سكشن (بما فيها video_carousel)، البانرات المستقلة، والموارد والتشغيلات والملفات الرقمية الخاصة؛ ويدعم استيراد 1.0.0 حتى 1.4.0.

  • تفريغ كامل للمنتجات والأقسام والأسعار بصيغة JSON نظيفة
  • تجميع كافة الصور ومجلد uploads/ بجودتها الأصلية
  • قالب بيانات للنقل إلى متجر فارغ — لا يشمل الطلبات والعملاء أو أسرار الأكواد

استيراد وزرع حزمة متجر (Import & Seed)

رفع وتثبيت بيانات وصور قالب متجر جديد

ارفع ملف حزمة المتجر بصيغة .zip لاستيراد المنتجات والأقسام والصور تلقائيًا إلى المتجر المحدد.

عند التعطيل (الافتراضي): إذا كان المتجر فارغًا يتم الزرع الكامل، وإذا كان قائمًا يتم الدمج والتحديث الذكي بدون حذف الطلبات. عند التفعيل: يحذف الكتالوج السابق ويعيد البناء (للمتاجر بدون طلبات فقط).

دليل إرشادات زرع وتجهيز الحزم (SEED_GUIDE.md)

1. الهيكل المعتمد لحزمة المتجر (Package Structure)
my_store_package.zip
├── manifest.json       # معلومات القالب، رقم الإصدار، نوع النشاط
├── settings.json       # إعدادات المتجر والهوية والحسابات
├── categories.json     # قائمة الأقسام والتصنيفات
├── products.json       # قائمة المنتجات والأسعار والمواصفات
├── delivery_zones.json # مناطق ورسوم التوصيل
├── resources.json      # الموارد والسعة وأيام العمل (اختياري)
├── batches.json        # التشغيلات والصلاحية (اختياري)
├── digital_assets.json # بيانات الملفات الخاصة (اختياري)
├── private_assets/     # الملفات الرقمية الخاصة بالبيع
└── uploads/            # مجلد الصور المنظم (branding, categories, products)
2. أنواع الأنشطة المدعومة (Business Domains)
  • Supermarket: سوبر ماركت، بقالة، تجزئة طازجة ومجمدة (دعم البيع بالقطعة أو الكيلو).
  • Restaurant: مطاعم، كافيهات، وجبات سريعة، صوصات وإضافات.
  • Pharmacy: صيدليات، مستحضرات تجميل، أدوية ومستلزمات طبية.
  • AutoParts: قطع غيار سيارات، موديلات، ورقم OEM.
  • Electronics: أجهزة منزلية وإلكترونيات وهواتف وضمان.
  • GeneralRetail: محلات ملابس وأزياء ومقاسات وألوان.

اختر activityPreset لتجهيز مواصفات النشاط. يدعم المحرك في الإصدار 1.3.0 الـ 17 نوع سكشن (بما فيها معرض الفيديوهات video_carousel وملفات .mp4 / .webm حتى 30MB)، وضغط الصور المخصص، وإعادة ربط معرفات الأقسام والمنتجات والروابط تلقائياً.

  • التوافق مع PostgreSQL: تأكد من كتابة جميع التواريخ في ملفات JSON (مثل updatedAt, exportedAt, countdownTarget) بصيغة التوقيت العالمي UTC المنتهية بـ Z.
  • الوضع الذكي والوضع النظيف: الاستيراد العادي (cleanFirst=false) يزرع المتجر الفارغ بالكامل أو يدمج التحديثات مع المتجر القائم، بينما cleanFirst=true يستبدل الكتالوج إذا لم توجد طلبات.
3. التثبيت المستقل (Standalone Installation)

إذا رغبت في استخراج هذا القالب وتركيبه كـ موقع مستقل بالكامل لعميل خاص على سيرفره المنفصل، يتم تصدير الحزمة وضبط المتغير في appsettings.json: "DeploymentMode": "StandaloneInstance".
