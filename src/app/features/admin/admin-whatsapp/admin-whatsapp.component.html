السياسات والضوابط التشغيلية

رسائل معاملات موثقة فقط قصر الرسائل على تأكيد الطلب، خروج التوصيل، اكتمال الطلب، ورمز OTP بموافقة العميل.
عدم تعطيل الطلبات عند فشل الإرسال في حال انقطاع الواتساب يظل الطلب محفوظاً وتتابع مهام المطبخ بصورة طبيعية دون توقف.
طابور إرسال Outbox دائم إعادة محاولات محدودة ومحسوبة مع حفظ سجل الإخفاق المنقح لتدقيق المشرف.
